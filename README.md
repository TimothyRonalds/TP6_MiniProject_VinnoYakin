# TP6 Mini Project - Agenda Tugas Siswa

Proyek aplikasi konsol Kotlin untuk mengelola agenda tugas siswa secara terstruktur.

## Identitas
- **Nama**: Vinno Yakin
- **Kelas**: XI RPL
- **Mata Pelajaran**: Mobile Programming

## Fitur Utama
1. Tambah Tugas
2. Tampilkan Daftar Tugas
3. Cari Tugas berdasarkan ID
4. Ubah Status Tugas (Selesai / Belum)
5. Hapus Tugas (Fitur Tambahan)
6. Tampilkan Statistik Tugas (Fitur Tambahan)
7. Penyimpanan Data ke File Teks (`agenda_tugas_tp6.txt`)
